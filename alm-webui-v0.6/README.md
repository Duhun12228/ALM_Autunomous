v0.4.1의 **모든 기능을 그대로 유지**하면서 시각 디자인을 전면 교체한 버전입니다.

```
alm-webui-v0.6/
├── index.html            마크업 (0번 화면 + 콘솔 4탭)
├── assets/
│   ├── obsidian.css      콘솔 스타일시트
│   ├── landing.css       0번 화면(Cold Start) 스타일시트
│   ├── app.js            원본 로직 (색상 리터럴 2줄만 변경)
│   ├── motion.js         시그니처 연출 애드온
│   └── landing.js        0번 화면 부팅 시퀀스 + 라이브 프리뷰
└── README.md
```

## 실행

`index.html`을 브라우저에서 열면 됩니다. 빌드 과정 없음.

웹폰트는 CDN에서 불러오므로 최초 실행에는 인터넷 연결이 필요합니다. 오프라인 환경(로봇 온보드 등)에 배포할 때는 아래 두 파일을 내려받아 `assets/fonts/`에 두고 `index.html`의 `<link>`를 교체하세요.

## 디자인 방향

**카드도 사이드바도 없다. 얇은 선과 여백, 그리고 계기.**

핀테크 대시보드가 아니라 정밀 계기반을 참조합니다. 세 가지 원칙으로 요약됩니다.

1. **정보는 상자에 담기지 않는다** — 카드·그림자 없이 1px 헤어라인과 여백으로만 구획
2. **숫자는 굵게가 아니라 얇게 키운다** — 볼드 대신 웨이트 150
3. **평소엔 조용하고, 이상이 생겼을 때만 개입한다** — 색은 안전 상태에만 배정

### 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `--void` | `#0A0C0F` | 페이지 바탕 (푸른 기가 도는 흑연) |
| `--raise` | `#121519` | 떠 있는 요소만 (모달·드로어·토스트) |
| `--hair` | `rgba(255,255,255,.075)` | 모든 구획선 |
| `--brass` | `#D8C4A0` | 유일한 악센트 — 라벨, 활성 상태, 진행 트랙 |
| `--ice` | `#6FA8FF` | 파형과 경로 등 데이터 표현에만 |
| `--ok` / `--warn` / `--danger` | `#4ADE9B` / `#F5A524` / `#FF4D4F` | 안전 상태 전용 |

브라스를 넓은 면적에 칠하지 마세요. 이 디자인의 인상은 색이 아니라 대비와 여백에서 나옵니다.

### 타이포그래피

| | 서체 | 역할 |
|---|---|---|
| 한글 | **SUITE Variable** | 본문·라벨의 한글 전부 |
| 숫자·기술값 | **Geist Mono** | 숫자 전부, 영문 라벨, ROS 토픽명 |

둘 다 SIL Open Font License입니다.

**웨이트 150은 오타가 아닙니다.** Geist Mono는 가변 폰트라 정수 사이 값을 쓸 수 있습니다. 200은 큰 크기에서 미세하게 두껍고, 100은 획이 끊겨 보입니다. 그 사이가 이 디자인의 인상을 결정합니다.

**작은 글자일수록 자간을 벌립니다.** 10px 라벨에 `letter-spacing: .24em`은 과해 보이지만 이게 맞습니다. 반대로 큰 숫자는 `-.04em`으로 조입니다.

**이탤릭은 화면당 두 곳 이하로.** Geist Mono의 이탤릭은 기울인 게 아니라 따로 그린 서체라 곡선이 살아 있습니다. 아껴 쓸 때만 효과가 납니다. 현재 적용 위치: 히어로 상단 상태 문구, 값이 없는 항목(`미지원`).

## 0번 화면 — Cold Start

페이지를 열면 콘솔 위에 **부팅 시퀀스 랜딩**이 얹혀 있습니다. 토스식 스크롤 랜딩의 기법을 가져오되, 성격은 마케팅이 아니라 **시스템이 스스로를 점검하며 켜지는 과정**으로 바꿨습니다.

- **스크롤 = 부팅 진행률.** 좌측 세로 게이지가 스크롤에 따라 차오르고, `power → sensors → mapping → safety → ready` 체크가 하나씩 점등됩니다. 바닥에 닿으면 100%가 되고 "진입" 버튼이 기다립니다.
- **살아있는 프리뷰.** 4개 계통 소개 카드는 정적 스크린샷이 아니라 `app.js`의 캔버스 감각을 축소 재현한 실제 애니메이션입니다 — 포인트클라우드가 돌고, 로봇이 경로를 따라 움직이고, 파형이 그려지고, 데드맨 패드가 순환 점등됩니다.
- **0.5초 세이프티 섹션.** 이 시스템의 핵심 가치를 화면 중앙에 초대형 숫자로 고정(sticky)해 스크롤에 맞춰 또렷해지게 했습니다.
- **진입 / 복귀.** "관제 콘솔 진입"을 누르면 랜딩이 걷히며 매핑 탭이 드러납니다. 언제든 상단 **ALM 로고**를 눌러 0번 화면으로 돌아옵니다. 우상단 "건너뛰기"로 즉시 진입도 가능합니다.

스크롤 등장 연출은 CSS 네이티브 `animation-timeline: view()`로 처리하고, 미지원 브라우저(2026년 기준 Safari)에서는 `@supports`와 `prefers-reduced-motion` 폴백으로 **모든 내용이 애니메이션 없이 그냥 보이게** 했습니다. 부팅 게이지만 크로스브라우저 일관성을 위해 JS로 구동합니다.

## 시그니처 인터랙션

### 길게 눌러 비상정지

HUD 우측의 붉은 원형 버튼을 **0.9초간 누르고 있어야** 발동합니다. 테두리 링이 그 시간 동안 한 바퀴 차오르고, 손을 떼면 즉시 되감깁니다. 짧은 클릭은 무시됩니다.

오조작 방지가 디자인에 내장되는 구조입니다. `Enter` / `Space` 누르고 있기로도 동일하게 동작합니다 — 접근성이자 안전 요건입니다.

발동하면 화면 전체에 붉은 파동이 한 번 지나가고 HUD 하단선이 붉게 잠깁니다. 해제는 기존과 같이 `정지 해제` 문구를 입력해야 합니다.

### 앰비언트 파형

모니터링 화면의 CPU 이력이 카드에 갇히지 않고 화면 좌우 끝까지 흘러나갑니다. 위쪽은 바탕색으로 페이드아웃시켜 숫자를 방해하지 않습니다.

### 값 변경 감지

숫자가 실제로 바뀔 때만 미세하게 굴러 들어옵니다. `motion.js`가 DOM을 다시 쓰지 않고 읽기만 하므로 `app.js`와 충돌하지 않습니다.

## app.js 변경 내역

**로직은 한 줄도 바꾸지 않았습니다.** 색상 리터럴 2줄만 조정했습니다.

`drawSystemChart()` 내부 (원본 762 / 764행):

```diff
- ctx.strokeStyle = '#edf1f6';
+ ctx.strokeStyle = 'rgba(255,255,255,.07)';

- const lines = [['cpu','#2f6fff'],['gpu','#8c61ff'],['ram','#12b76a']];
+ const lines = [['cpu','#6FA8FF'],['gpu','#A88BFF'],['ram','#4ADE9B']];
```

캔버스에 하드코딩된 색이라 CSS로 덮을 수 없고, 그대로 두면 흑연 배경 위에 근백색 격자가 그려집니다. SVG 지도의 색상값도 같은 이유로 `index.html`에서 교체했습니다. 둘 다 색상이지 로직이 아닙니다.

### CSS로 덮은 것

`app.js`가 **생성하는** SVG 요소(웨이포인트, 측위 후보)는 `fill` 속성이 JS에 하드코딩되어 있습니다. 이건 CSS가 프레젠테이션 속성을 덮어쓸 수 있어 스타일시트에서 처리했습니다.

```css
#waypointLayer circle{fill:var(--ice);stroke:#0B0E13}
#candidateLayer circle{fill:var(--violet)}
```

### 주의 — `.manual-control-zone.disabled`

`app.js`는 이 클래스를 **한 번도 제거하지 않습니다.** 여기에 `pointer-events:none`을 걸면 수동주행 버튼이 영원히 죽습니다. 조작 차단은 `app.js`가 실제로 관리하는 `.drive-button[disabled]`와 `#manualLockOverlay`로 판단하도록 했습니다.

```css
#tab-manual .hero:has(#manualLockOverlay:not(.hidden)) .manual-control-zone{opacity:.3}
```

## 남은 코드 이슈

디자인 작업 범위 밖이지만 실서비스 전에 처리해야 합니다.

| 우선순위 | 이슈 | 위치 |
|---|---|---|
| **높음** | `innerHTML` 무이스케이프 삽입. 실제 ROS 로그·맵 이름이 들어오는 순간 인젝션 경로가 됩니다 | `toast()` `renderLogs()` `renderWaypoints()` `openModal()` |
| **높음** | 데드맨 패드가 키보드로 조작 불가. `setPointerCapture` 때문에 `pointerleave` 폴백도 죽어 있습니다 | `bindEvents()` |
| 중간 | 탭 잠금이 경고 토스트만 띄우고 실제 전환을 막지 않습니다 | `switchTab()` |
| 중간 | `drawPointCloud`가 탭과 무관하게 매 프레임 1700포인트를 그립니다. Jetson CPU 예산 30%와 충돌 | `drawPointCloud()` |
| 낮음 | 설정 드로어의 프로필 카드가 `state.profile`과 동기화되지 않아, 매핑 화면에서 바꾼 값이 되돌아갑니다 | `openSettings()` |

E-STOP 홀드는 `motion.js`에서 키보드를 지원하지만, **수동주행 데드맨 패드는 여전히 포인터 전용**입니다. 이건 `app.js` 수정이 필요해 이번 범위에서 제외했습니다.
